# ⚖️ AI Legal Chatbot

An AI-powered legal assistant designed to help users understand the Indian Constitution and legal concepts through an interactive conversational interface.

## 🚀 Features

* **AI-Powered Responses:** Uses a locally running LLM through Ollama to answer legal questions.
* **Indian Constitution Support:** Provides information about constitutional articles and legal provisions.
* **Legal Knowledge Base:** Uses a knowledge base to support responses to legal queries.
* **Interactive Interface:** Offers a user-friendly chatbot interface built with Streamlit.
* **Privacy-Friendly Processing:** Runs the language model locally, helping reduce reliance on external AI APIs.
* **Text and Audio Support:** Includes generated audio responses and audio-related assets.

## 🛠️ Technologies Used

* Python
* Streamlit
* Ollama
* Large Language Models (LLMs)
* NumPy

## 🎯 Objective

The goal of this project is to make legal information more accessible by allowing users to ask questions about the Indian Constitution and receive AI-generated explanations in a conversational format.

## ⚙️ Getting Started

1. Install Python and Ollama.

2. Download the required language model using:

   `ollama pull llama3`

3. Install the Python dependencies listed in `requirements.txt`.

4. Start the application using:

   `streamlit run app.py`

## ⚠️ Disclaimer

This chatbot is intended for educational and informational purposes only. Its responses may contain inaccuracies and should not be treated as professional legal advice. Consult a qualified legal professional for advice on specific legal matters.
